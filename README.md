# Blackjack Game

A simple browser-based blackjack game built with HTML, CSS, and JavaScript. Players can place a bet, start a round, draw cards, stand, and see the dealer play out the hand.

## Features

- Player name prompt on load
- Bet placement before each round
- Start game, draw cards, and stand actions
- Dealer turn logic
- Chip balance and pot tracking
- Simple win/loss/push results

## How to Run

1. Open the project folder in a browser.
2. Launch [index.html](index.html) directly, or serve the folder with a local static server.

Example with Python:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Project Structure

- [index.html](index.html) – Main page layout
- [styles.css](styles.css) – Styling for the game UI
- [script.js](script.js) – Game logic and bet handling
- [images/](images/) – Background and game assets

## Notes

This project is a beginner-friendly blackjack demo and is intended for learning and casual play.
